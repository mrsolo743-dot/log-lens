# Инструкция: проверка и загрузка log-lens на GitHub

## 1. Проверка проекта на своём компьютере

Нужен Python 3.9 или новее (`python --version`). На Windows вместо `python3` пишите `python`.

```bash
cd log-lens

# 1) запустить на готовом демо-логе: текст в терминал
python -m log_lens analyze examples/sample.log.gz

# 2) построить HTML-отчёт и открыть его в браузере
python -m log_lens analyze examples/sample.log.gz -o report.html
#   Windows:  start report.html     macOS: open report.html     Linux: xdg-open report.html

# 3) сгенерировать свой тестовый лог и проверить фильтры
python -m log_lens generate -n 10000 --days 3 -o demo.log
python -m log_lens analyze demo.log --status 4xx --top 5
python -m log_lens analyze demo.log --last 6h --exclude-bots --output json
```

Если у вас есть настоящий лог nginx/Apache, попробуйте и его: `python -m log_lens analyze путь/к/access.log -o real.html`.

### Тесты

```bash
pip install pytest
python -m pytest -q            # ожидается: 61 passed (или часть skipped без Playwright)

# необязательно: браузерные тесты HTML-отчёта
pip install playwright
python -m playwright install chromium
python -m pytest -q            # 61 passed
```

### Что посмотреть в HTML-отчёте

- карточки со сводкой наверху и блок «Подозрительная активность»;
- подсказки при наведении на график «Запросы во времени»;
- клик по заголовку таблицы (сортировка) и поле «Фильтр…»;
- кнопка «Тема» в правом верхнем углу (авто, светлая, тёмная);
- на телефоне или в узком окне вёрстка перестраивается в одну колонку.

Созданные при проверке файлы `report.html`, `demo.log` и т. п. в корне проекта перечислены в `.gitignore` и в репозиторий не попадут.

## 2. Загрузка на GitHub

> Если вы напишете мне «загружай», я сделаю это сам. Ниже те же шаги для ручного запуска.

1. Создайте пустой репозиторий: https://github.com/new
   - **Repository name:** `log-lens`
   - **Description:** `Анализатор access-логов nginx/Apache: статистика, поиск атак и автономный HTML-отчёт (Python, без зависимостей)`
   - **Public**
   - **Не** ставьте галочки *Add a README*, *.gitignore* и *license*: эти файлы уже есть в проекте.
2. В папке проекта выполните:

```bash
cd log-lens
git init
git add .
git commit -m "log-lens: анализатор access-логов nginx/Apache с HTML-отчётом"
git branch -M main
git remote add origin https://github.com/mrsolo743-dot/log-lens.git
git push -u origin main
```

Если установлен GitHub CLI (`gh`), первый шаг можно заменить командой:

```bash
gh repo create mrsolo743-dot/log-lens --public --description "Анализатор access-логов nginx/Apache: статистика, поиск атак и автономный HTML-отчёт"
```
